PurityWallet is a self-custody Bitcoin Purity (BTC1) wallet. No account or sign-in is required. On a fresh installation, tap Add a wallet to create or import a wallet. The default Electrum server is electrum.bitcoinpurity.org:50002 (TLS); users can configure another server in Settings. Lightning wallet creation and Lightning network settings are unavailable in this release. Existing BlueWallet app data does not migrate automatically into this separate app container. No in-app purchase is required. Optional iOS payment notifications use the BitcoinPurity backend at https://notifications.bitcoinpurity.org.
